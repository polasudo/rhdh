## FBCs

For File-based catalogs (FBC), each FBC Component must be in its own Application, and one Application is needed per OpenShift version.

See link:../build/scripts/renderCatalogs.sh[renderCatalogs.sh] to update the catalogs with new Containerfile metadata.

npx skills add redhat-developer/rhdh-skill --skill konflux-tekton-updates
