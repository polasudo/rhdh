### Container publishing guides

* link:https://docs.google.com/document/d/1oLzKgCXblERauGj2r3_WI-um69jXZfZ9O8pPLambYRQ/edit#heading=h.gznx4jn2ize2[Onboarding into Comet] (internal metadata management tool for the RH Ecosystem Catalog) - this is where you enable/disable Freshmaker, add people to your team, define the names of your Product Manager (PM) and Program Manager (PgM), and compose the text that will appear in the catalog for your containers and bundles. Much of this is orchestrated by CPaaS, but some it not.
* link:https://source.redhat.com/groups/public/container-build-system/container_build_system_wiki/new_container_image_end_to_end_workflow[New Container Image End to End Workflow]

NOTE: You need access to the LDAP link:PERMISSIONS.adoc[devel group] in order to run/manage container builds locally with `rhpkg` and `brew`.
