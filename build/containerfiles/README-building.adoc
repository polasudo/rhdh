# Gitlab builder images

The Containerfile(s) in this folder are used to create images that are then used for gitlab runners.

The are published to https://quay.io/repository/rhdh/gitlab-runner?tab=tags

Images include certs to allow pushing changes to RH GL repos such as this one.

Images are based on the plugin catalog builder image @ https://quay.io/rhdh/plugin-catalog-builder-rhel9

See also https://issues.redhat.com/browse/RHIDP-7998

[NOTE]
====
If the version of yarn changes in distgit/containers/rhdh-hub/.yarnrc.yml be sure to update the Containerfile(s) too.
====

## Node 22 runner

For 1.5-1.9 using link:https://catalog.redhat.com/search?gs&q=nodejs-22&searchType=containers[node 22], from the root of this repo, run the following to build and publish an updated container:

```
TODAY=$(date +%Y%m%d-%H%M); \
podman rmi quay.io/rhdh/plugin-catalog-builder-rhel9:1.10 -f; \
podman build . --no-cache -f gitlab-runner.Containerfile --label quay.expires-after=99d \
    -t quay.io/rhdh/gitlab-runner:1.10-$TODAY \
    -t quay.io/rhdh/gitlab-runner:1.10-yarn3-node22 \
    -t quay.io/rhdh/gitlab-runner:1.10 && \
podman push quay.io/rhdh/gitlab-runner:1.10-$TODAY; \
podman push quay.io/rhdh/gitlab-runner:1.10-yarn3-node22; \
podman push quay.io/rhdh/gitlab-runner:1.10
```
